# LumaFin 1.2.0

LumaFin now looks the same on every screen, and there's more you can set up your way.

- **Request movies and shows:** with the SeerrFin plugin on your server, Home shows what's trending and coming soon, plus your own requests and where each one stands. Request missing seasons right from a show's page.
- **New settings:** a full-screen layout with a category menu and Back to Home at the bottom.
- **Make Home yours:**
  - Choose the top bar style.
  - Pick landscape or portrait cards.
  - Pin genres, studios, playlists and Favorites.
  - Remove shows from Up Next.
  - Choose which libraries appear in the side menu.
- **Your server's Home layout:** if your server uses the Home Screen Sections plugin, LumaFin can show its rows.
- **One look everywhere:** cards, spacing, row titles and the clock now match across Home, libraries, details pages, actor pages and search. Cards show the year and rating.
- **Better details:** episode pages show the show's main cast as well as guest stars. Top Rated favours well-reviewed titles. Titles with only a poster show it in full.
- **Fixes:**
  - Home no longer jumps back to the top while you browse.
  - Titles you're watching again no longer show a watched check.
  - Search opens on a clean background.
  - Subtitles are shown above the player controls.
