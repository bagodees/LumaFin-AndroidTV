# Instructions for AI coding assistants

LumaFin is a fork of the official Jellyfin Android TV app. These rules apply to every
assistant working in this repository (Claude, ChatGPT/Codex and others).

## Follow the roadmap in order

- Read [ROADMAP.md](ROADMAP.md) before starting feature work. It names the **current
  version**.
- Only work on issues in the current version's milestone. Don't start items from a later
  version, even if they look easy or related, unless the owner explicitly approves it in
  the conversation. Note any approved exception in the issue.
- New ideas go to a later milestone or "1.x later"; don't add them to the version in progress.
- Bug fixes for the released app belong in 1.0.x and can be done at any time.
- Redesign details are in [docs/redesign-plan.md](docs/redesign-plan.md).

## Before finishing

- Keep ROADMAP.md and the GitHub issue in sync with what was done (check off items,
  comment on the issue).
- Don't publish releases, store submissions, posts or other public changes without the
  owner's explicit approval.
